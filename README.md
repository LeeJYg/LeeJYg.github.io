# leejyg.github.io

이주영(Lee JooYoung)의 개인 이력서 사이트. Jekyll + GitHub Pages로 배포합니다.

- 라이브: https://leejyg.github.io
- 내용 수정: `_data/data.yml` 한 파일에서 전부 관리합니다

## 로컬 실행

```bash
bundle install
bundle exec jekyll serve   # http://localhost:4000
```
